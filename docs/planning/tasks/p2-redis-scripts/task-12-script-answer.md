## Notes and decisions

- **Lua scoring is tested against the shared vectors without a time override.** The script takes its time from Redis `TIME`, so the vectors can't set the receive time. A test-only time parameter in production would let a caller choose the receive time, so it was ruled out. Instead, `points.lua` holds only the scoring function; it is prepended to `answer.lua` at load, and the tests run that exact function over `points_cases.json`. Each real answer's points are also checked against Go's `Points()` for the receive time Redis returned.
- **`WAIT` goes through `pipe.Do("wait", …)`:** go-redis's `Pipeliner` has no `Wait` method (checked in its source), so the generic command keeps `EVALSHA` and `WAIT` on one connection. `Replicated` is set when enough replicas acknowledged; with `WAIT` disabled it stays false.
- **Early close** uses the same condition as `quiz.EarlyClose`, moves only `close_at`/`next_at`, schedules the close for now, and publishes a `state` event in the same script.
- `scoring.Service` applies the 250 ms timeout, passes rejections through, maps unexpected replies to `ErrInternal` and any infrastructure failure to `ErrServerBusy`, and **never retries** (TRD §9.3).
- The `Repository` mock is generated by mockgen (`//go:generate`); mock directories are now covered by `check-generated`.
- `testenv.StartReplica` starts a replica on the test network when a test needs it.
